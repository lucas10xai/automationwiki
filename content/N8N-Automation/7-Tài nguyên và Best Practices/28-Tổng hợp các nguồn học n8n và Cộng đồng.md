# 🌍 Tổng hợp các nguồn học n8n và Cộng đồng

> [!info] Tổng quan
> n8n có một hệ sinh thái tài liệu và cộng đồng rất phong phú. Bài này tổng hợp tất cả nguồn học chính thống, kênh cộng đồng, và công cụ hỗ trợ để bạn không bao giờ bị "stuck" khi gặp vấn đề.

---

## 📚 Tài liệu chính thức

### 1. n8n Documentation
🔗 [docs.n8n.io](https://docs.n8n.io)

Đây là nguồn tài liệu **chính xác và đầy đủ nhất**. Luôn tra cứu tại đây trước khi tìm ở nơi khác.

| Mục | Nội dung |
|---|---|
| **Getting Started** | Hướng dẫn cài đặt nhanh |
| **Integrations** | Tài liệu từng node tích hợp |
| **Code** | Expressions, Code Node reference |
| **Hosting** | Self-host, Docker, Cloud |
| **API** | REST API của n8n |
| **Advanced AI** | LangChain, AI Agents, Memory |

---

### 2. n8n Blog
🔗 [blog.n8n.io](https://blog.n8n.io)

Các bài viết chuyên sâu về use cases thực tế, tutorials mới nhất, và cập nhật tính năng từ đội ngũ n8n.

---

### 3. n8n Templates Library
🔗 [n8n.io/workflows](https://n8n.io/workflows)

Thư viện **hơn 1000+ workflow templates** miễn phí, có thể import trực tiếp vào n8n của bạn. Tìm kiếm theo:
- Tên ứng dụng (Slack, Gmail, HubSpot...)
- Use case (CRM, Marketing, DevOps...)
- Độ phức tạp

## 🤝 Cộng đồng

### 1. n8n Community Forum (Chính thức)
🔗 [community.n8n.io](https://community.n8n.io)

Nơi **đặt câu hỏi tốt nhất** — đội ngũ n8n và contributors tích cực trả lời. Trước khi đăng câu hỏi, hãy tìm kiếm vì hầu hết vấn đề đã được giải đáp.

**Mẹo dùng Forum hiệu quả:**
- Cung cấp screenshot hoặc JSON của workflow
- Mô tả rõ bạn đang cố làm gì, đã thử gì, lỗi là gì
- Gắn tag phù hợp: `help`, `bug`, `feature-request`

---

### 2. Discord Server
🔗 [discord.gg/n8n](https://discord.gg/XPKeKXeB7d)

Chat real-time với cộng đồng. Có các channel riêng:
- `#help` — Hỏi đáp nhanh
- `#showcase` — Khoe workflow của bạn
- `#resources` — Chia sẻ tài nguyên

---

### 3. Reddit
🔗 [reddit.com/r/n8n](https://reddit.com/r/n8n)

Thảo luận, use cases, và meme 😄. Tìm kiếm trước khi đăng.

---

### 4. GitHub
🔗 [github.com/n8n-io/n8n](https://github.com/n8n-io/n8n)

- **Issues:** Báo cáo bug
- **Discussions:** Feature requests
- **PRs:** Đóng góp code
- **Releases:** Theo dõi changelog phiên bản mới

## 🛠️ Công cụ & Extension hữu ích

### n8n AI Assistant
Trong n8n UI (phiên bản mới), có tích hợp **AI Chat** để hỏi về cách xây dựng workflow, debug lỗi, và giải thích node — hoàn toàn miễn phí.

### HTTPie / Postman
Test API endpoints trước khi đưa vào n8n workflow — tránh mất thời gian debug vì sai URL hay body format.

### JSON Formatter
🔗 [jsonformatter.org](https://jsonformatter.org) — Format và validate JSON trước khi dùng trong n8n.

### RegEx101
🔗 [regex101.com](https://regex101.com) — Test biểu thức regular expression trực quan trước khi dùng trong Filter/Code node.
